# Triage Labels

The engineering skills use five canonical triage roles. This table maps each
role to its GitHub label and records the intended presentation.

| Role | GitHub label | Color | Description |
| --- | --- | --- | --- |
| `needs-triage` | `needs-triage` | `FBCA04` | Maintainer evaluation required |
| `needs-info` | `needs-info` | `D876E3` | Waiting for reporter information |
| `ready-for-agent` | `ready-for-agent` | `0E8A16` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | `1D76DB` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | `FFFFFF` | Will not be actioned |

When a skill names a triage role, use the corresponding GitHub label from this
table.
